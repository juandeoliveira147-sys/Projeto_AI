# AI 2.0

## Descrição

A AI 2.0 é a evolução do meu primeiro projeto em Python. Nesta versão, o código foi totalmente reorganizado em classes e funções, tornando a aplicação mais organizada, reutilizável e fácil de manter.

O principal objetivo deste projeto foi colocar em prática conceitos importantes da linguagem Python, como modularização, orientação a objetos básica, manipulação de arquivos JSON, tratamento de exceções e organização de código.

Além disso, esta foi a primeira versão da assistente capaz de **lembrar informações do usuário** através de um arquivo JSON, permitindo que ela reconheça o usuário nos próximos acessos.

---

## Funcionalidades

* Assistente virtual interativa.
* Memória persistente utilizando arquivo JSON.
* Reconhecimento automático do usuário.
* Calculadora organizada em funções.
* Jogo "Adivinhe o Número" com três níveis de dificuldade.
* Tratamento de erros utilizando `try` e `except`.
* Código organizado em classes e responsabilidades separadas.

---

## Estrutura do projeto

* **Coração da AI**

  * Carrega a memória da assistente.
  * Salva novas informações.
  * Realiza o primeiro acesso do usuário.
  * Gerencia o arquivo `memoria.json`.

* **Menu da AI**

  * Recebe o usuário.
  * Exibe as opções disponíveis.
  * Controla a navegação da aplicação.

* **Calculadora**

  * Operações matemáticas.
  * Tratamento de divisão por zero.
  * Validação de entradas.

* **Adivinhe o Número**

  * Três níveis de dificuldade.
  * Mensagens aleatórias de feedback.
  * Retorno automático ao menu principal.
