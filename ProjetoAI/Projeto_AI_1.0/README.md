# Projeto_AI 1.0

Este foi o meu primeiro projeto de Inteligência Artificial em Python.

O objetivo deste projeto foi colocar em prática os conhecimentos adquiridos durante meus estudos iniciais da linguagem, focando principalmente em lógica de programação, estruturas de decisão, laços de repetição, tratamento de erros e interação com o usuário pelo terminal.

## Funcionalidades

* Assistente virtual que conversa com o usuário pelo nome informado no início da execução.
* Calculadora interativa com as operações:

  * Soma
  * Subtração
  * Multiplicação
  * Divisão
* Tratamento de erros para entradas inválidas.
* Tratamento para divisão por zero.
* Jogo "Adivinhe o Número".
* Dois níveis de dificuldade no jogo.
* Menu principal para navegar entre as funcionalidades.

## Tecnologias utilizadas

* Python
* Biblioteca `random`

## Objetivos de aprendizado

Durante este projeto pratiquei:

* Estruturas condicionais (`if`, `elif`, `else`)
* Laços de repetição (`while`)
* Funções da biblioteca `random`
* Tratamento de exceções (`try` / `except`)
* Organização da lógica do programa
* Interação com o usuário através do terminal

## Próximas melhorias (implementadas na AI 2.0)

Na versão 2.0 o projeto foi completamente reorganizado e recebeu diversas melhorias:

* Refatoração completa do código utilizando classes.
* Separação das responsabilidades do programa.
* Sistema de memória permanente utilizando arquivos JSON.
